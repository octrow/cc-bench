# ADR-0002: Скоуп v1 - свои репо, Tier P автоматом, Tier F полуавто

Дата: 2026-07-30. Статус: принято (гриль-сессия, Daniil).

## Контекст
"Чужой" репо ломает половину харнесса: нет .env, нет наших гейтов,
нет реальных тикетов. Tier F (реальные задачи + слепой судья) - главный
источник методологических ошибок m1 (утечки контекста, судья с неверным
baseline) и ~60% объёма работы.

## Решение
1. v1 работает на своих репо (web-backend-new, voice-agent-constructor-
   backend): контролируем .env, гейты, задачи. Чужие репо - v2.
2. Tier P (пробы с answer key) - полный автомат: прогоны, проверка
   ответа, метрики, отчёт.
3. Tier F - полуавто: инструмент делает клоны, армы, прогоны, гейты,
   диффы, экстракцию метрик, анонимизацию диффов. Судейство - отдельный
   ручной шаг вне инструмента.

## Последствия
- Судейский пайплайн не автоматизируем в v1 - меньше поверхность ошибок.
- Пробы и answer keys пишутся и замораживаются ДО прогонов.
