# ADR-0001: Бенчмарк - это инструмент, а не разовый эксперимент

Дата: 2026-07-30. Статус: принято (гриль-сессия, Daniil).

## Контекст
m1/m2 показали: харнесс собирается руками под каждый прогон
(archive-m1-m2/prepare-m2.sh, archive-m1-m2/finish-tails.sh, OTEL-блок из archive-m1-m2/MANUAL.md, пересчёт
активного времени). Каждый новый замер - снова ручная сборка.
Цель - повторяемая цифра ДО/ПОСЛЕ для любой пары (репо, тулза):
skill, rtk, openspec, graphify, headroom, gh-axi и т.д.

## Решение
Делаем отдельный репозиторий-инструмент (не скрипты в sdd-kit,
не разовый план). sdd-kit остаётся одной из измеряемых "тулз".
PLAN-tools.md переквалифицируется: это план ПЕРВОГО применения
инструмента, а не самостоятельный эксперимент.

## Последствия
- Новый репо = обвес: README, установка, версии. Принимаем.
- Харнесс m1/m2 портируется в репо как основа (клоны, армы,
  OTEL, гейты, экстракция) - не переписываем с нуля.
- Инструмент en-only (портируемость), отчёты - на языке юзера.
