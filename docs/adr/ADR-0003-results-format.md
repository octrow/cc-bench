# ADR-0003: Результаты - CSV + markdown-отчёт

Дата: 2026-07-30. Статус: принято (гриль-сессия, Daniil).

## Решение
- Одна строка на (arm, task, run) в results.csv: токены по типам и
  моделям, cost_usd, turns, tool calls, активное время, гейты,
  fired-check, success.
- Отчёт ДО/ПОСЛЕ - markdown: median + IQR по армам, дельта, вердикт.
- Сырьё (OTEL export, транскрипты, диффы) сохраняется рядом в logs/
  прогона - для ad-hoc разбора.

## Отклонено
- DuckDB + Grafana/Metabase: оверкилл до десятков экспериментов.
- "Только сырьё, анализ ad-hoc": теряется повторяемость отчёта.
